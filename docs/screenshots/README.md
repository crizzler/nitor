# Screenshots

These images are generated by `tools/screenshot.py`, which runs the interface offscreen against the
**mock backend**. Nothing in them was captured from real hardware, and the lighting shown is the
mock's, not a photograph of LEDs.

That is deliberate: screenshots have to be reproducible without the hardware, and the project does
not want to imply a tested-device claim it cannot back up. Whether real LEDs light up is tracked
separately and honestly in [`../hardware-notes.md`](../hardware-notes.md).

Regenerate them with:

```bash
PYTHONPATH=src python3 tools/screenshot.py
```
